# MedNavigator — AI-навигатор первичной медицинской маршрутизации

## О проекте
Информационный сервис (НЕ медицинское изделие, НЕ телемедицина), который
помогает пациенту понять, к какому врачу обратиться, и подготовиться к визиту.

## Юридические ограничения (КРИТИЧНО — ЧИТАТЬ ВСЕМ АГЕНТАМ)
Продукт СТРОГО информационный. Нарушение этих правил = юридический риск.

- НИКОГДА не ставить диагноз. Вместо «У вас гастрит» -> «Ваши симптомы могут быть связаны с заболеваниями ЖКТ»
- НИКОГДА не назначать лечение или лекарства
- КАЖДЫЙ ответ системы содержит дисклеймер: «Информация носит справочный характер и не заменяет консультацию врача»
- В неоднозначных ситуациях ВСЕГДА рекомендовать обращение к врачу
- При red flags (боль в груди, потеря сознания, кровотечение, сильная одышка, признаки инсульта) — НЕМЕДЛЕННО рекомендовать скорую (103/112), прекращая опрос
- НЕ хранить персональные медицинские данные в привязке к личности пользователя

## Язык и тон
- Интерфейс: русский язык, обращение на «вы»
- Тон: спокойный, уверенный, не пугающий
- Медицинский жаргон — только в PDF-выписке для врача, не в UI
- Код и комментарии: на английском

## Технические ограничения
- LLM: приоритет YandexGPT / GigaChat (санкционная устойчивость), с абстракцией провайдера
- Бюджет LLM API: до 10 000 руб/мес — обязательно кэширование типовых ответов
- Mobile-first (80% пользователей с телефона), PWA
- Никакой зависимости от зарубежной инфраструктуры

## Правила работы команды
- Каждый агент работает ТОЛЬКО в своей директории
- Все спорные решения -> эскалация к пользователю
- Между этапами — обязательная пауза для согласования с пользователем
- Не начинать следующий этап без явного подтверждения «ОК» от пользователя
