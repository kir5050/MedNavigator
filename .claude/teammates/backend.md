# Роль: Backend-разработчик

## Ответственность
Реализация серверной части: API, LLM-интеграция, медицинская база знаний,
триаж-логика, PDF-генерация, аналитика.

## Зона ответственности (файлы)
- backend/** — весь серверный код

## Задачи по этапам

### GATE 1: Медицинская база знаний + LLM-ядро

1. Медицинская база знаний (backend/app/medical_kb/):
   - 50 частых симптомов с бытовыми синонимами на русском
   - Маппинг: симптомы -> группы заболеваний (НЕ диагнозы, а области)
   - Маппинг: группы -> врачебные специальности (>=20 специальностей)
   - Red flags с немедленным триажем (ЭКСТРЕННО)
   - Чеклисты подготовки к визиту для каждого специалиста
   - Формат: JSON/YAML файлы

2. LLM-абстракция по контракту от архитектора:
   - Интерфейс LLMProvider
   - Реализация для YandexGPT (приоритет) и GigaChat
   - Fallback при недоступности провайдера

3. Цепочка промптов (backend/app/prompts/):
   - Промпт 1: Извлечение симптомов из свободного текста
   - Промпт 2: Генерация адаптивных уточняющих вопросов
   - Промпт 3: Триаж (определение срочности) — ПЕРЕСТРАХОВКА
   - Промпт 4: Маршрутизация к специалисту с обоснованием
   - Промпт 5: Генерация описания для PDF в мед. терминологии
   - В КАЖДЫЙ промпт встроить юридические guardrails

4. Кэширование типовых ответов

### GATE 2: Backend API полный цикл

1. FastAPI-приложение с эндпоинтами по контракту архитектора
2. Все endpoints: session/start, session/{id}/message, session/{id}/result,
   session/{id}/pdf, feedback, analytics/dashboard
3. Генерация PDF-выписки:
   - Жалобы в медицинской терминологии (МКБ-10)
   - Хронология, сопутствующие факторы, текущие лекарства
   - Рекомендованный специалист, вопросы для врача
   - QR-код, дата, дисклеймер

### GATE 4: Аналитика

1. Сбор метрик (SQLite): опросы/день, распределение срочности,
   ТОП специалистов, конверсия воронки, NPS
2. Защищенный эндпоинт для дашборда
