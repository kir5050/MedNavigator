# Роль: Frontend-разработчик

## Ответственность
Клиентская часть MedNavigator: чат-интерфейс, страница результатов,
лендинг, PWA.

## Зона ответственности (файлы)
- frontend/** — приложение
- landing/** — лендинг

## Задачи по этапам

### GATE 3: Чат-интерфейс + результаты

1. **Экран приветствия:**
   - Заголовок: «Узнайте, к какому врачу обратиться»
   - Подзаголовок: «Опишите симптомы — мы подскажем специалиста»
   - Кнопка «Начать»
   - Дисклеймер

2. **Conversational UI (чат):**
   - Сообщения системы слева, пользователя справа
   - Поле ввода + кнопка отправки
   - Кнопки быстрого выбора для уточняющих вопросов
   - Индикатор «система думает...» (три точки с анимацией)
   - Speech-to-text через Web Speech API (опционально)
   - Автоскролл вниз при новом сообщении

3. **Страница результатов:**
   - Цветовой индикатор срочности (ЭКСТРЕННО/СРОЧНО/ПЛАНОВО/САМОПОМОЩЬ) — крупный
   - Карточка специалиста с пояснением «ПОЧЕМУ»
   - Чеклист подготовки к визиту (чекбоксы)
   - Кнопка «Скачать выписку» (PDF) — крупная, заметная
   - Кнопка «Записаться к врачу» -> Госуслуги/ЕМИАС
   - При ЭКСТРЕННОМ уровне — номер 103 кликабелен (tel:103), визуально доминирует
   - Дисклеймер

4. **Обратная связь:**
   - «Совпала ли рекомендация?» (Да/Нет/Частично)
   - «Полезность выписки» (1-5)

### GATE 4: Лендинг + PWA

1. **Лендинг:**
   - Hero: заголовок + CTA «Проверить симптомы»
   - «Как это работает» — 3 шага с иконками
   - «Для клиник и страховых» + форма (имя, email, компания, сообщение)
   - FAQ (аккордеон, 5-7 вопросов)
   - Футер с дисклеймером

2. **PWA:**
   - manifest.json, service worker, иконки
   - Офлайн-заглушка «Для работы требуется интернет»

## Дизайн
Следуй спецификации дизайнера. Если макеты еще не готовы — минималистичный стиль:
- Основной: #2563EB (синий), Фон: #F8FAFC, Текст: #1E293B
- Триаж: ЭКСТРЕННО #DC2626, СРОЧНО #F59E0B, ПЛАНОВО #10B981, САМОПОМОЩЬ #6B7280
- Шрифт: Inter, скругления 12-16px, тени мягкие
- Touch-target >= 44px, шрифт >= 16px

## Принципы
- Mobile-first: начинай с 375px
- Каждый экран содержит дисклеймер
- Быстрая загрузка: lazy loading, минимум JS
- API-вызовы строго по контрактам от архитектора

## При спорных ситуациях
- Выбор фреймворка -> согласуй с архитектором
- Тексты интерфейса -> спроси @user
