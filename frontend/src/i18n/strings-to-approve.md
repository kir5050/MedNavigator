- Описание над текстом бэкенда: *нет* — показываем `res.emergency_message` /
  `res.message` дословно, никаких UI-обёрток над текстом.

## Прочее

- `Открыть PDF` — короткая форма для PDF-CTA на маршрутном листе
  (текущая «Скачать маршрутный лист (PDF)» сохранена как основной вариант).
- `Начать новый опрос` — без изменений (существующая строка).
- Status pill `● Онлайн` — **в этом PR убран** (новая строка, имитирует
  живое присутствие; не возвращать без согласования). Если возвращать —
  без упоминания времени ответа.

## Удалено из дизайн-референса (не выкатывать без согласования)

- `МN / 26`, `MN / v1.4` — fake document IDs
- `120+ врачей`, `94%`, `~1.8с` — фейковые метрики
- «Картина вырисовывается», «Боль давящая или пульсирующая?» и любые
  sample-реплики из дизайна — не хардкодить; все реплики ассистента
  приходят с бэкенда.
- `Без диагноза и назначений · не заменяет врача` — короткая форма
  дисклеймера. На result используется существующая продакшн-строка
  «Информация носит справочный характер…» дословно.
- `103`, `112`, hotline-лейблы в crisis UI — не хардкодим; номера только
  из `res.emergency_message`.
